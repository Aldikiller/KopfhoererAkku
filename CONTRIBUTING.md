# Mitarbeit

Fehler mit Windows-Version, Programmversion, Kopfhörermodell und klaren
Schritten melden. Keine Bluetooth-Adressen, vollständigen Gerätekennungen
oder unbereinigten Diagnoseprotokolle öffentlich hochladen.

Änderungen in einem Branch entwickeln, `build.ps1` ausführen und relevante
Tests beschreiben. Bei Bluetooth-Änderungen echte Verbindung/Trennung testen.
Beiträge werden unter der MIT-Lizenz dieses Projekts eingereicht.
KI-Unterstützung bei relevanten Änderungen transparent angeben.
