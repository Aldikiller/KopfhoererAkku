# Sicherheitsmeldungen

Diese Beta hat keine garantierte Supportdauer. Bitte die neueste verfügbare
Version verwenden. Keine sensiblen Daten in öffentliche Issues schreiben.

Nach Veröffentlichung des Repositorys kann der Herausgeber unter GitHub
Settings → Security → Private vulnerability reporting einen privaten
Meldeweg aktivieren. Solange das nicht erfolgt ist, ist hier kein privater
Kontaktkanal eingerichtet. Sicherheitsdetails nicht in öffentliche Issues
stellen; gegebenenfalls zunächst ohne technische Details um Kontakt bitten.

Die Anwendung verlangt keine Administratorrechte. Build-Werkzeuge und
GitHub-Workflows sind getrennt von der Anwendung und können Netzwerk benötigen.
