# Kopfhörer-Akku

A free Windows app that shows the battery levels of up to two Bluetooth headphones in the system tray, a desktop widget, or both.

Choose **English** under **Einstellungen → Allgemein → Sprache / Language**, then click **Speichern**. The interface changes immediately and remembers your choice. German is the default.

You can change device labels, colors, symbols, fonts and battery shape. The widget also has independent size, opacity, position and layout settings. Settings include a live preview, low-battery warnings, optional startup and an optional GitHub update check, which is off by default.

Requires Windows 10 build 19041 or newer, or Windows 11, x64, with .NET Framework 4.8. Only battery levels provided by Windows and the device drivers can be displayed. Tested with JBL Live 770NC and JLab Rewind 2; other models may behave differently. Downloads are currently unsigned.

[Source code](https://github.com/Aldikiller/KopfhoererAkku) · [Published releases](https://github.com/Aldikiller/KopfhoererAkku/releases)

Free and open source under the MIT license. No ads or telemetry. The optional update check sends your IP address and app version to GitHub, but does not send device names or battery levels. No updates are installed automatically.
