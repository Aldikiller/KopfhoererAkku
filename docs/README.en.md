# Kopfhörer-Akku

## One-click audio switching in the widget too · 1.6.1

Click a headphone icon, name or battery value in the desktop widget to select its audio output. A green check marks the active output. Dragging moves the widget without switching audio; double-click opens settings. Selection works with the position locked too. The widget shares the tray mappings and the Audio quick selection setting.

## Switch audio output with one click

Click a tray battery icon to send Windows audio to that headphone. A green circle with a white check marks the active output. Unique matching devices are assigned automatically; otherwise choose the output once under Audio quick selection. Saved manual assignments are preserved.

![Audio output](Audio-Direktwahl-1.6.0.png)

Battery checks default to 30 seconds, configurable from 30 to 300 seconds. No rapid extra checks or routine progress banners. App updates are checked manually or optionally at startup.

[English website](https://aldikiller.github.io/KopfhoererAkku/en.html) · [English guide](https://github.com/Aldikiller/KopfhoererAkku/wiki/English)

A free Windows app that shows the battery levels of up to two Bluetooth headphones in the system tray, a desktop widget, or both.

Choose **English** under **Einstellungen → Allgemein → Sprache / Language**, then click **Speichern**. The interface changes immediately and remembers your choice. German is the default.

You can change device labels, colors, symbols, fonts and battery shape. The widget also has independent size, opacity, position and layout settings. Settings include a live preview, low-battery warnings, optional startup and an optional GitHub update check, which is off by default.

Requires Windows 10 build 19041 or newer, or Windows 11, x64, with .NET Framework 4.8. Only battery levels provided by Windows and the device drivers can be displayed. Tested with JBL Live 770NC and JLab Rewind 2; other models may behave differently. Downloads are currently unsigned.

[Source code](https://github.com/Aldikiller/KopfhoererAkku) · [Published releases](https://github.com/Aldikiller/KopfhoererAkku/releases)

Free and open source under the MIT license. No ads or telemetry. The optional update check sends your IP address and app version to GitHub, but does not send device names or battery levels. No updates are installed automatically.

Languages: Deutsch · English · Español · Français · Українська. Choose a language in general settings and save. German remains the default.

From version 1.3.1, settings open in a simple view with battery warnings, display mode, icon style and language. Select Advanced settings to access all detailed controls. Unsaved changes are preserved when switching views. Save applies them; Close discards them.
