# Device symbol examples

Original simple vector drawings by Aldikiller, MIT license, same as the application. Five transparent white symbols: over-ear, on-ear, in-ear, headset and speaker. SVG files are editable source templates. The app imports their supplied PNG counterparts, or your own PNG/ICO file. Arbitrary SVG import is not supported.

Choose Settings > Names & display > Choose icon. The app copies and normalizes the file into its local settings folder. Maximum input size: 4 MB and 2048 pixels per dimension. Preview against light and dark backgrounds. Widget: enable Tiny and the image-only option to show the imported device symbol alone.
