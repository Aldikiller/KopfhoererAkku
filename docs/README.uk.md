# Kopfhörer-Akku

**Поточна версія: 1.6.5**

## Що нового у версії 1.6.5

- Стандартний і міні-віджет: два значки для натискання, налаштування розміру, розташування, шрифтів, кольорів і прозорості. Міні-віджет показує назву та стан при наведенні; необов’язкове прилипання до країв екрана. Віджет можна приховати та показати через меню; значок у треї залишається доступним.

- Окремі попередження для навушників із власним порогом і кольором. Світлове попередження: 1–90 %, період 1–10 секунд, яскравість 10–100 % або постійне світіння. Тест справжнього значка протягом 30 секунд. Пауза попереджень на 30, 60 або 120 хвилин без додаткових запитів Bluetooth.

- Три власні сполучення клавіш: перемикання, навушники 1, навушники 2. Поєднуйте Ctrl, Alt, Shift і Win з A–Z. Спочатку вимкнено; недоступні сполучення позначаються.

- Необов’язкова пам’ять гучності для навушників: задайте початковий рівень; далі програма запам’ятовує гучність при виході з пристрою та відновлює її під час вибору аудіовиходу. Вимкнення звуку та мікрофон не змінюються.

- Імпортуйте PNG/ICO в розділі назв і відображення через Вибрати значок. П’ять прикладів SVG і PNG містяться в docs/symbols. SVG — редаговане джерело; імпортується PNG/ICO. Міні-віджет може показувати лише зображення. У треї підвищено контраст; віджет зберігає початкові кольори.

- Стани розрізняють від’єднання, невідоме з’єднання, відсутність рівня заряду Windows і помилку запиту. Збережені значення не подаються як підтверджене поточне вимірювання.

## Вибір аудіо також у віджеті

Натисніть значок, назву або відсоток заряду навушників у віджеті, щоб вибрати їхній аудіовихід. Зелена позначка показує активний вихід. Перетягування переміщує віджет без зміни звуку; подвійне натискання відкриває налаштування. Вибір працює і з заблокованою позицією. Віджет використовує ті самі призначення й налаштування швидкого вибору, що й значки в треї.

## Перемикайте аудіовихід одним натисканням

Натисніть значок акумулятора, щоб перемкнути звук Windows на ці навушники. Зелене коло з білою позначкою показує активний вихід. Пристрої з однозначною відповідністю призначаються автоматично; інакше один раз виберіть вихід у швидкому виборі аудіо. Ручні призначення зберігаються.

![Audio output](Audio-Direktwahl-1.6.0.png)

Типовий інтервал перевірки акумулятора — 30 секунд, можна налаштувати від 30 до 300 секунд. Без частих додаткових перевірок і звичайних повідомлень про перебіг. Оновлення перевіряються вручну або, за бажанням, під час запуску. · Українська

## Змінити мову

Відкрийте Einstellungen → Allgemein → Sprache / Language, виберіть Українська й натисніть Speichern. Інтерфейс зміниться одразу, а вибір збережеться. Типова мова — німецька.

## Встановлення

Завантажте інсталятор або повністю розпакуйте портативний ZIP. Увімкніть навушники, підключіть їх до Windows і виберіть до двох пристроїв у програмі. Якщо записи дублюються, виберіть запис із рівнем заряду.

## На ваш смак

Змінюйте назви, кольори, символи, шрифти й форму батареї. Попередній перегляд показує зміни перед збереженням.

## Віджет і налаштування

Подвійне клацання значка відкриває налаштування, праве — меню. У Відображення й віджет виберіть трей, віджет або обидва. Змініть розмір, положення, прозорість, шрифти й розташування. Для прозорого тла встановіть непрозорість тла й товщину контуру на нуль.

## Вчасні сповіщення

Сповіщення про низький заряд, необов’язковий запуск разом із Windows і добровільна перевірка оновлень. Оновлення не встановлюються автоматично.

## Вимоги й обмеження

Windows 10 від збірки 19041 або Windows 11, x64, з .NET Framework 4.8. Відображаються лише дані, надані Windows і драйвером. Перевірено з JBL Live 770NC та JLab Rewind 2. Інші моделі ще не підтверджено. Значення можуть надходити із затримкою. Файли поки не мають цифрового підпису. Windows може показати попередження.

## Допомога

Якщо пристрою немає, перевірте підключення Windows, виберіть його знову й дочекайтеся наступної перевірки. Шукайте приховані значки під ^ біля годинника. Сповіщення потребують підтвердженого з’єднання; режим Не турбувати може їх приховувати.

## Приватність і ліцензія

Без реклами й телеметрії. Налаштування залишаються на вашому комп’ютері. Необов’язкову перевірку оновлень типово вимкнено. Під час її використання GitHub отримує IP-адресу й версію програми, але не назви пристроїв чи рівні заряду. Відкритий код за ліцензією MIT, без гарантій у межах, дозволених законом.

## Видалення

Видаліть встановлену версію через Параметри Windows → Програми. Налаштування залишаються в %LOCALAPPDATA%\KopfhoererAkku. Для портативної версії вимкніть автозапуск, закрийте програму й видаліть її папку.

Вкажіть модель навушників, версії Windows і програми та кроки відтворення проблеми. Не публікуйте Bluetooth-адреси чи приватні дані.
